## Featured Projects

### Distributed Inverted-Index Search Engine
Distributed document search engine in Java where many clients index disjoint document collections in parallel and stream results to a central gRPC server that merges them into a thread-safe global inverted index. Benchmarked concurrent indexing throughput across client counts. — *Java, gRPC, Protocol Buffers, Maven*

### DocuQuery AI — Document Q&A with Hybrid Retrieval
A document Q&A tool that answers questions about PDFs and cites the source page for every answer, combining keyword (BM25) and semantic (vector) search via Reciprocal Rank Fusion. Includes an evaluation harness measuring retrieval quality. — *Python, LangChain, FAISS, Gemini, FastAPI, Streamlit*

### ActivityHub — Personal Activity Timeline
Full-stack app that aggregates activity from Spotify, GitHub, Google Calendar, and Discord into one timeline, with OAuth 2.0 flows and automatic per-provider token refresh. — *React, ASP.NET Core, EF Core, OAuth 2.0*

### Space Explorer — iOS NASA Data Explorer
Native iOS app in SwiftUI (MVVM) that browses three NASA feeds — daily astronomy photo, image search, and near-Earth asteroid tracking — using async/await. — *Swift, SwiftUI, MVVM*

### Study Planner — iOS Study Tracker
Native iOS study planner in UIKit with Core Data persistence and a Pomodoro timer backed by local notifications. — *Swift, UIKit, Core Data*
